# Robotistan Internship Portfolio

Welcome to my internship repository! This repository contains the source code, hardware designs, and documentation for the projects I developed during my internship at **Robotistan**. 

During my time as a Maker and Content Creator Intern, I gained hands-on experience in embedded systems, circuit design, hardware integration, and technical communication. My primary focus was bridging the gap between complex hardware engineering concepts and accessible educational content for the maker community.

## 🚀 Key Responsibilities & Contributions

- **Hardware Prototyping & PCB Design:** Contributed to the end-to-end design and development of multiple printed circuit boards (PCBs). This included schematic capture, PCB layout routing, footprint configuration, resolving DRC errors, and generating Gerber files for manufacturing.
- **Embedded Systems Development:** Designed and implemented interactive, hands-on electronics projects utilizing a wide range of platforms including Arduino (Uno, Nano, Q series), ESP32 microcontrollers, and Raspberry Pi.
- **Technical Content Creation:** Authored technical blog articles and developed educational video scripts for the company's social media channels. I focused on demonstrating the working principles, features, and practical applications of various development boards, sensors, and electronic components.

## 🛠️ Highlighted Projects & Folder Structure

*Below is a summary of the key projects included in this repository:*

- **📁 Custom PCB Designs:** Designed an Arduino Uno clone PCB and LM2596 buck/boost converter layouts from scratch using EDA tools.
- **📁 [Eye Tracking Mouse](eye-tracking-mouse/README.md):** Raspberry Pi 5 gaze-controlled mouse using OpenCV eye tracking and blink clicking.
- **📁 ESP32 Wireless Macro Keyboard:** Built a custom 3-button Bluetooth macro pad using Outemu Brown mechanical switches and the BleKeyboard library.
- **📁 Ultrasonic Radar System:** Created a 180-degree radar tracking system using an Arduino Uno, HC-SR04 sensor, SG90 servo, and Processing for the visual interface.
- **📁 Ambilight Monitor Backlighting:** Engineered a dynamic RGB LED backlighting system for monitors using an Arduino Nano, WS2812B strips, and the FastLED library.
- **📁 [Smart Cleaning Robot](smart-cleaning-robot/README.md):** Arduino-based mobile cleaning robot with fan-assisted debris collection and ultrasonic obstacle detection.
